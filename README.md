# SIBANSOS

Sistem Informasi Bantuan Sosial Pemerintah Desa Suka Maju.

Dibuat dengan PHP Native, MySQL, dan Bootstrap 5.

## Fitur
- Login admin dan warga
- Kelola data warga dan jenis bantuan
- Pengajuan bantuan dan unggah berkas
- Verifikasi, penyaluran, monitoring, dan laporan cetak

## Cara menjalankan
1. Salin folder ke htdocs (XAMPP)
2. Import database.sql lewat phpMyAdmin
3. Buka /setup.php sekali untuk membuat akun contoh
4. Buka http://localhost/sibansos
